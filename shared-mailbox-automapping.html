Set FullAccess automapping
Preflight checks, confirmation, change, and verification.
Enter valid mailbox and delegate emails to generate the script.

        
What the script does
  1. Checks that the target is a shared mailbox and the delegate is an individual mailbox user or mail user.
  2. Reads the delegate’s direct, allowed FullAccess permission. It stops if the permission lookup fails or a direct deny exists.
  3. Shows the resolved identities and asks for a Y before any change. If a direct grant exists, it removes that grant, then adds FullAccess with the selected automapping value. Otherwise it adds the grant.
  4. Reads the resulting FullAccess permission. Exchange does not expose the automapping flag in this permission output, so verify Outlook behavior after propagation.

        
Group-based access is not changed. This script changes FullAccess only; it does not grant Send As or Send on behalf. Microsoft’s automapping guidance
